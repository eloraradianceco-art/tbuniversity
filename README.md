## Use
1. In GitHub: **Settings → Pages → Deploy from a branch → `main` / root → Save**.
2. Open `https://<your-username>.github.io/<repo-name>/` on your phone.
3. Safari: **Share → Add to Home Screen**. Android Chrome: **Install app**.

Progress saves in the browser on each device. Each course is a single self-contained `index.html`.
